# YOLO26l 512×384 静态部署

512×384 保持 4:3。以 640×480 文件源为例，宽和高各缩小至 0.8 倍，模型输入含 196608 像素。
文件回放直接使用预先整形的 RGB888 帧，完整调用从逐帧输入准备到 PS 无 NMS 解码。
执行范围及决策见 [ADR_59](../../ADR/ADR_59.md)。

## 离线基线

原权重 SHA256 与 640×640 导出一致。PyTorch／ONNX Runtime 三组比对通过，末端仍输出最多 300 个
检测候选。Icraft 3.39.0 的 parse、optimize、quantize、adapt、generate 原生退出均为 0。
校准采用原数据划分的前 32 张校准图和 PSA 混合策略，在矩形尺寸重算统计。生成图 428 HardOp、
0 个 Host 计算节点、89 组静态视图通过。Conv／Matmul 运算量为 41.570 GOP／帧，
当前混合精度标称算术下界 5.690ms。量级来自逻辑图核算，完整耗时以板端报告为准。

三份完整模拟输出各有 338688 个 FP32 元素，均有限。实图六个高分框属于相同类别并可逐一匹配，
最小 IoU 0.90143，最大 score 差约 0.28683，原框差异门限失败。矩形 FP32 在同一 32 图留出代理集
得到 mAP50–95 58.685%，原方形 FP32 为 61.037%。矩形 PSA 生成图模拟在同一留出集得到
58.557%。这组 32 图代理集包含 218 个标注，正式精度仍待扩大验证。现阶段以性能为主要门槛，
完整保存数值原差异。

本机产物见 `.local/yolo26-rect-export-r1`、`.local/yolo26-rect-calibration-r1`、
`.local/yolo26-rect-compile-r1`、`.local/yolo26-rect-psa-r1` 及 `-sim0-r1` 至 `-sim2-r1`。
`numerical-review.json` 保存全部高分匹配及完整张量哈希，`compute-budget.json` 保存逐层运算量。

## 首轮板测

ARM64 13 项测试通过。原 BOOT 下用同一张文件输入完成 30 次推理，前 3 次预热，后 3 次读取
逐 HardOp 原生时间，以下统计中间 24 次。使用公开 FP32 输出读取，89 组实际内存视图一致。

| 阶段 | 均值 ms | P95 ms |
|---|---:|---:|
| RGB 归一化 | 2.186 | 2.218 |
| 写入 SDK Host Tensor | 1.349 | 1.392 |
| 状态清理 | 0.013 | 0.014 |
| 提交与原生完成等待 | 27.661 | 27.710 |
| 读取输出 | 1.348 | 1.371 |
| PS 无 NMS 筛选与解码 | 3.512 | 3.563 |
| 完整调用 | 36.079 | 36.200 |

均值折算 27.72 次／秒，串行平均还需缩短 2.745ms。原生时间按经核验的逐项耗时解释，
Conv2d 共 17.610ms，Cast 2.005ms，Matmul 1.435ms。待进一步检查慢层的空间分块和
CPU 输入／尾处理拷贝。板端完整输出有限，板端对生成图模拟 RMS 为 0.641，原严格框门限失败。
SDK 正常关闭、设备分配归零、所有者为空。该轮无采集、BOOT 写入或重启。
实测、失败原值和 SHA256 见 [rectangular-baseline-r1](evidence/rectangular-baseline-r1.json)。
原始记录在 `.local/yolo26-rect-board-r1`。

## 访存候选

首轮热点 P3 分类塔 #3441／#3443 各耗时约 0.556ms，#3412 约 0.372ms。
编译指令中分别请求 12.25、12.25、5.67 倍唯一输入字节。单纯改变空间高宽解释，以
16／24／48／96 为宽重新生成，四组均保留原读请求数。实际像素分组并调整排列后，
三层核心读请求比均为 1。计入前后转置，16／16／8 分组把三个区域的累计读写请求
由 43.940MiB 降至 21.830MiB。这些是指令覆盖量，未测得物理 DDR 字节。

三个完整生成图模拟输出均与原矩形生成图不同。同一实图的高分候选从 6 个降至 1 个，
其余两张低纹理输入在已用门限下无高分框，仍存在原始张量差异。静态 95 组视图和
操作读写覆盖通过，数值门槛失败，候选不进入板测。完整请求量和数值记录见
[rectangular-layout-r1](evidence/rectangular-layout-r1.json)。

## 保持模型数据流的运行时优化

矩形图使用公开 HostDevice 接口，让 SDK Host Tensor 引用程序拥有的 FP32 归一化数组。
数组上的对象生命周期覆盖 Tensor、会话和原生完成。保留 PS 到 NPU 的实际传输与公开输出读回。
两阶段 TopK 在完整有限值扫描之后，先排除在任何类别下都达不到阈值的低分位置。
阈值边界使用原 sigmoid，位置并列和类别顺序沿用原比较规则。

连续文件序列按实际完成计数验收，测量定义见 [METRICS](METRICS.md#矩形文件序列)。
原图身份保持为首轮矩形基线；首张用首轮实图原始字节，用于完整原始张量对照。

首轮连续序列在 600 秒完成 18291 次，平均 30.485 FPS。600 个窗口中 295 个为 31 次、
301 个为 30 次、4 个为 29 次。延迟 P50／P95／P99 为 32.679／33.081／33.315ms，
最长完成间隔 78.968ms，严格逐秒目标未通过。归一化和尾处理均值为 2.191／1.546ms，
Host 输入拷贝为 0，提交＋等待约 27.624ms。同场景首份完整板端输出与首轮文件基线逐字节一致。
32 张图的完整输出均不同且有限，计时中 571 次与计时后 32 次完整同源比较通过。
ARM64 编译无警告，13 项测试、原生关闭及分配归零通过。正常重启一次，原 BOOT 保持相同，
没有启动摄像头。见 [序列 r2](evidence/rectangular-sequence-r2.json)。

序列中 31 张可配对的标注留出图（194 标注）用于同输入的板端代理评估。
板端 PSA 的 mAP50–95 为 59.923%，同子集生成图模拟为 59.556%，同子集 FP32 为 60.044%。
放宽精度后开展的性能比较沿用原值，这组代理集仅用于定位。板端对模拟的严格框 fixture
通过 11／31，二者逐图差异仍存在。原始分数、张量和留出身份见
[板端代理对照](evidence/rectangular-board-proxy-r2.json)。

同模型与同一序列使用等位 NEON FMA 后，归一化均值由 2.191ms 降至 1.478ms，
600 秒完成 18649 次，平均 **31.082 FPS**，P95 32.355ms。32 份完整原始输出均与
标量归一化版本逐字节一致。最慢一次完整调用为 1.925s，第 24／25／26／518 秒
分别完成 27／0／8／25 次，严格逐秒仍失败。各检查点进程 RSS 131428KiB，原生关闭、
设备分配归零。文件系统为 ext4，预热落盘 32 个完整张量，实际大停顿未定位到具体阶段，
保留为时延诊断对象。[序列 r3](evidence/rectangular-sequence-r3.json)

最终版将预热张量延后到 SDK 关闭后写盘，计时段保持无额外 SSH 轮询。600 秒完整测量
获得 **18492 次／30.820 FPS**。492 个一秒窗口各完成 31 次，其余 108 个各完成 30 次。
完整调用 P50／P95／P99 为 **32.321／32.714／32.930ms**，最大 73.538ms，
最大完成间隔 73.554ms。最慢调用的 forward 占 45.853ms，原生完成等待 22.975ms，
线程 CPU 约 30.964ms。此前 1.925s 调用缺少分段证据，根因保持开放。

32 份完整原始张量与前两轮同输入逐字节一致。计时中 578 次完整轮换抽查、结束后 32 次
同输入比较均通过。ARM64 13 项测试通过，编译无警告，SDK 原生退出 0、设备分配归零。
原 BOOT SHA256 一致，检查时共享锁可用且设备无所有者。三个 600 秒轮次各一次 SDK 及
正常重启，BOOT 写入与摄像头采集均为 0。严格逐秒结论适用于内存回放的推理主干，
包含 RGB 归一化、完整 Tensor 读回与 PS 解码。实屏及摄像头联合吞吐待验。

## 复现文件序列

输入文件由 2～32 张不同的无行填充 RGB888 依次拼接。每帧 589824 B，所有输出均绑定实际
张量尺寸。以下命令在仓库根运行，路径中的尖括号由本轮真实身份替换。准备包时提供已经
通过 ARM64 构建测试的 ELF、登记图和经独立核验的 BOOT 哈希。

```powershell
python FPGA/yolo26_lite/tools/package_probe.py --binary <ARM_ELF> --model <登记模型目录> --rgb-sequence <RGB序列> --seconds 600 --model-variant int8_psa_rect --output-read plain_fp32 --boot-sha256 <实际BOOT哈希> --output <新包目录>
python FPGA/yolo26_lite/tools/analyze_replay.py --run <板端返回目录> --output <新分析记录>
```

执行仍从 [SDK 有限测试包装器](SDK.md#有限测试包装器)启动，新的启动和包不得复用已经消费的许可。
