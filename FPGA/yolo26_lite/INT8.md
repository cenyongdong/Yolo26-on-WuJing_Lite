# INT8／FP16 混合精度开发

设计决定见 [ADR_56](../../ADR/ADR_56.md)，性能对照见 [NPU 诊断](NPU-DIAGNOSTICS.md)。
当前性能阶段接受完整 PSA 回退候选的 **59.97% 代理 mAP50–95**，优先推进 30FPS；
原先相对 FP32 损失不超过 1 个百分点的目标保留为后续评估项，原失败结果不回写。
控制变量精度对照已结束；有限板测当前完整调用最低 91.894ms，结果见本页后部。
59.97% 仍是固定模拟代理集结果，尚无板端整组 mAP 或真实摄像头精度通过结论。

当前使用 **PTQ（训练后量化）**：权重固定，只做浮点前向、KLD 范围测量和量化，
没有反向传播或权重更新，也没有进行 QAT（量化感知训练）。混合精度表示指定算子保留 FP16，
不表示采用 QAT。校准不读取标注；隔离留出集的精度评价才使用标注。

## 运算量与峰值预算

按本地 PSA 量化逻辑图核算，166 个 Conv 和 6 个 Matmul 共 **86.7956736 GOP／帧**，
每次乘加计两次运算；其中 INT8 卷积 78.381056 GOP、FP16 卷积 8.0459776 GOP、
FP16 逻辑 Matmul 0.36864 GOP。分块／Copy 不会因此变成额外的有用模型运算量。
核算器对 grouped Conv 的每组通道和 Matmul 广播做显式检查，3 项测试通过，见
[算术预算](evidence/int8-arithmetic-budget-r1.json)。

以标称 8TOPS INT8、4TFLOPS FP16 为假设，且采用相同乘加计数口径：
全 INT8 的 86.8G 算术时间约 10.85ms、约 92FPS；当前混合精度约
`78.381056 / 8 + (8.0459776 + 0.36864) / 4 = 11.9013ms`，约 84FPS。
这不是完整调用保证：未计其余算子、填充／重复计算、搬运、调度和未达到峰值的时间。
23FPS 相当于只有约 2TOPS 有效算力，不是上述标称值与模型运算量直接相除得到的上限。
这里的精度分类属于量化逻辑图；实际生成算子拆分、物理存储和计时仍按板端诊断判断。

到共享 Neck 特征即停止；将全部检测支路保留为 FP16，不把整个 Neck 扩大为浮点。
原生 `--batch` 现在通过 `--native-batch` 显式设置并进入身份记录，必须整除校准数量，
资源判断使用实测工作集而非参数名字。

## 校准量与精度回退的控制变量验证

32 图／1 分区候选的 32 张留出图已全部完成，mAP50–95 为 **0.58971043**，

原先 4→32 图同时改变了检测头精度，不能从这两个实验直接归因。

| 候选 | 校准图数／分区 | 每区图数 | 精度改动 | 要分离的因素 |
|---|---|---:|---|---|
| base32 | 32／1 | 32 | 完整检测头＋注意力核心 FP16 | 基准 |
| groups32 | 32／2 | 16 | 同基准 | 与 base32 比较分区影响 |
| cal96 | 96／6 | 16 | 同基准 | 与 groups32 比较图片数量影响 |
| psa32 | 32／1 | 32 | 完整三个 PSA 残差块 FP16 | 与 base32 比较注意力区域精度影响 |
| stem32 | 32／1 | 32 | 仅追加第 2 个卷积 #3 及 SiLU #4 为 FP16 | 与 base32 比较一个早期卷积的影响 |

所有候选使用相同 FP32 图／权重、同一校准池顺序及相同的 32 张留出图。PSA 与早期卷积实验
复用 base32 的浮点特征统计，但重算权重统计，避免把精度变化和数据变化混在一起。
`psa_detection` 沿每个块的两次残差 Add 回溯到其输入，覆盖 QKV、位置卷积、投影和两层 FFN，
不越过块输入扩展至 Backbone；原 Matmul／Softmax 本来就是 FP16，不能把结果解释成首次将 Softmax 改为浮点。

跨精度 features 复用先完成独立 4 图对照：从检测头策略的统计生成 PSA 策略，所得量化 JSON／RAW
与 PSA 策略重新测量的产物逐字节一致。实际 32 图 psa32 为 126 个 INT8／40 个 FP16 卷积、
449 个 HardOp；stem32 为 140 个 INT8／26 个 FP16 卷积。
两候选的量化／适配／生成均原生退出 0、无 Host 计算；静态视图分别 98／94 组通过。
