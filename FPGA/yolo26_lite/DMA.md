# 自研视频 DMA

`y26_dma_mm2s.sv` 将内存行变成流，`y26_dma_s2mm.sv` 将流写回内存。
两者是独立命令／响应端点，不包含物理地址分配、缓存同步、CSR 时钟跨域或 HP2 仲裁。
集成层必须提供 AXI ID 路由／检查；本核只允许一个在途突发，不支持交织返回。

## 命令与响应

命令包含 32bit 总线地址、16bit 行字节数／行数、32bit 行步长及 tag。
起始地址和步长要求 8 字节对齐；步长至少是行字节数向上取整至 8 字节。
源分配必须覆盖行尾额外读取的填充字节；写端通过 WSTRB 保留填充区原值。
地址末尾使用 64bit 运算检查，防止 32bit 环绕。

每个 burst 至多 16×8 字节，并在 4KiB 边界拆分，LEN 为实际拍数减一。
读端先收齐并检查一个 burst，再发送；错误 burst 不发布。
写端先收齐一个 burst，才发布独立的 AW 和 W；任何一方都不等待另一方 READY 才产生 VALID。

| status | 含义 |
|---|---|
| 0 | 成功 |
| 1 | 非法命令，未发起总线访问 |
| 2 | 读响应错误，已等待 LAST |
| 3 | 写响应错误，不表示内存未被改动 |
| 4 | LAST／流 KEEP／帧行边界错误 |
| 5 | STOP 后安全排空 |

读端 `rsp_bytes` 统计实际交给下游的字节；写端 `rsp_bytes_acked` 只统计收到 OKAY 的字节。
两者不能互相代替。响应由 ready/valid 握手消费前，busy 保持，响应载荷不变。

## 停止顺序

1. 停止提交新任务，对整条受影响流水线保持 STOP。
2. 读端保留已呈现 AR／流拍，排空被接受的读事务；写端完成已发布 AW/W/B。
3. STOP 期间写端在本地 idle/reply 仍接收并丢弃上游流拍，避免上下游互等。
4. 所有 DMA、预处理管线和扫描消费者分别证明停止后，才归还内存、消费响应和撤销 STOP。

`drained` 只证明该模块没有在途外部事务和待发布流拍，不能证明整个系统停止。
缺失 RLAST 时一直 busy，软件超时不能强行释放缓冲。复位须覆盖整个 AXI 事务域。
未知 FSM 状态不会自动转为 idle 冒充停止。

# 分拍描述符检查器

`y26_dma_descriptor.sv` 在无总线副作用的独立状态机中检查二维地址包络。
16×32 乘法拆成两个 16×16 产品，保留完整 48bit 行偏移，再加上基址和向上取整的行字节数。
禁止先截断到 32bit 再判断溢出；终点恰好为 4GiB 时仍合法，因为实际最后一字节小于该终点。
响应保持到消费者接受；请求接受后调用方可以立即改变输入描述符。

130 项 XSim 测试通过，包含最大行宽／行数／步长、对齐、行填充、4GiB 边界及随机范围。
该模块已接入两路 DMA 与预处理顶层；原 83 项 DMA 测试重新通过（64651 周期）。
STOP 发生在检查期间时先消费本地检查响应，再报告停止，避免下一任务遭遇上一项仍在执行。
顶层额外进行源目标重叠检查。综合结果仍未通过整机时序要求，详见 [SYNTHESIS.md](SYNTHESIS.md)。
