# ADR_57：访存时间线与相邻卷积权重调度

## 性能变化

同一 ARM ELF、输入、SDK 和观察 BOOT 的实测，各组 24 次普通调用计算完整均值。

| 方案 | 完整调用均值 | #3404＋#3405 合计 |
|---|---:|---:|
| 原基线 | 83.215590 ms | 3.209216 ms |
| 仅 KLM 地址平移 | 82.460455 ms | 3.208192 ms |
| 跨层权重预取 | 83.218894 ms | 3.202901 ms |

预取使两层局部少 **0.006315 ms（约 0.20%）**，完整调用平均慢 0.003304 ms。本轮各组使用独立启动，KLM 平移组的目标层耗时近似，整机差异的归因仍待验证。独立的 #3405 输出通道分块对照中，完整调用由 82.596 ms 增至 82.767／83.496 ms。原图因此保留为性能基线。[实测与原值](../FPGA/yolo26_lite/MEMORY-TIMELINE.md) · [观察 BOOT 对照](../FPGA/yolo26_lite/evidence/prefetch-board-r1.json)

日期：2026-11-14。状态：本轮接口时间线与预取对照已完成，后续开发暂停，等待讨论。

## 决定

以当前 PSA 四区域混合图为基线，先取得硬件观测，再比较 #3404→#3405 权重预取与 #3405
层内分块。保持原权重、量化系数、数学和公开端口；先保存完整离线输出与地址证明，再进入
同程序有限板测，计入新增重排、指令和传输的完整调用时间。各模块分别提交。

第一步显式启用公开层进度／Tile 计数器采样，只作用于包中指定的诊断帧。SDK 单一所有者
依次读取物理列 1..cols，保存每组读取起止时刻与前后层计数；每帧最多 512 行，主动轮询
不超过 500ms。达到观察上限仅截断记录，后续仍执行原生 wait 和完整完成计数校验；
不通过计数变化、采样超时或进程退出提前释放硬件资源。

普通帧不启用采样，保持完整调用性能边界；诊断帧包括观测开销，不能混入性能均值。
旧 0..cols-1 数组原值保留，新记录使用显式指令列编号；其与寄存器索引的硬件对应关系仍待核实。
本轮 3 条板测时间线只观测到层进度，Tile 字段恒定，不能据此推断总线空闲或计算停顿。

## 观测能力边界

- 指令请求量、运行时 OCM／DDR 位置、逐层时间、实际总线事务分别保存。
- SDK 性能报告的数据结构包含由通信量／配置带宽计算的传输时间，不能当作逐周期测量。
- `configProfiler` 公开接口仅说明配置缓冲；当前未确认记录格式、触发条件和写入上界，
  不以猜测的缓冲大小启动。此限制不表示硬件不支持 Profiler。
- 公开 Tile 计数不是已验证的字节计数，也没有直接给出 MPE 停顿原因。若原生观测不足，
  必须补充真实 NPU—PL DDR 通路的被动监测；不得用软件生成的时间线代替实测。

## 权重预取候选

最终任务显示 #3404 每个相关 MPE 的 KLM 只占低地址 8KiB；#3405 单块权重为 18KiB，
当前最大地址范围 54KiB。按公开 INT8 Tile 地址模型推算可寻址范围为 64KiB。
这支持在独立地址区提前装入下一层权重的容量假设，尚不证明读写端口可并行或依赖已满足。

#3405 当前保留两块 18KiB 权重，并反复覆盖第三块。候选分别比较缩小搬运块与减少常驻块
来腾出轮换空间；不预设请求量较少就更快。任何跨层移动必须证明覆盖之前旧消费者已经完成、
新消费者等待搬运完成，且下一层不重复加载相同权重。

状态、实测和恢复入口统一见 [访存诊断](../FPGA/yolo26_lite/MEMORY-TIMELINE.md)。

## 输出通道实验决定

两支 128 通道和四支 64 通道均通过完整离线与板端逐位回归、真实无复制 Concat 地址核验。
后者让主权重重复请求从 5.5 倍降为 1 倍，但输入请求变为 4 倍，目标卷积从约 1.547ms
增到 2.794ms。拒绝将二者作为性能版本，保留原共享输入调度基线。后续权重调度必须
同时守住输入复用；不以主权重流量下降代替完整调用加速证据。数值统一见访存诊断页。

跨层候选先整体平移下一层 KLM 读写 8KiB，保守保留前层所有地址至其完成。
实际 8 个 MPE 的地址包络检查通过，最大 62KiB；这使预取容量假设具体可审阅，
但任务依赖与读写端口并行仍未证明，因此不生成可部署标记。原生完整任务必须保留精确
常数，拒绝直接从舍入文本日志恢复数学参数。

真实总线补测选择被动观察 NPU—AI_Mate 接口；记录握手、背压及原始地址，
不在数据通路插入仲裁或 ready，不把旧 HP2 诊断通路当成 NPU PL DDR。
观察器溢出只终止记录，不能影响 NPU 或充当硬件完成证明。组件仿真和整机物理实现、
板端观测分别验收；外部总线计数仍不能直接观察芯片内部 MPE 停顿原因。

观察记录使用 32KiB 片上 RAM，避免诊断本身写 DDR 干扰被测流量。新增独立 GP CSR，
通过已有异步邮箱读取冻结记录；GP 本地状态不依赖 NPU 时钟持续运行。邮箱两端协调复位，
保留完整命令序号及有限容量，不以停止观测替代 NPU 原生完成。新 CDC 采用有界数据路径
约束并排除旧例外覆盖；整机物理闭合之前不部署。该捕获链路联合仿真和综合通过，物理实现待验。

32KiB 初版在链接后超出器件 BRAM 容量一个 RAMB18 等效位置。记录区改为 16KiB、256 箱，
以 0.4ms 箱宽保持约 102.4ms 窗口；不修改主功能缓冲、器件或频率。原失败与新实现分开保留。

减深度仍不能消除宽端口的 BRAM 浪费，最终选择 32bit 深 RAM、每箱 16 拍串行写入。
0.4ms 箱间隔提供充足写入时间；过快输入由既有背压／溢出契约明确处理。可读计数及 closed
必须等最后一个记录字提交，不能把记录已接收误当全部持久到 RAM。组件综合实际占 4 个 BRAM。

软件采样显式纳入有限包契约，只在诊断帧启用；普通帧保持原性能边界。邮箱超时封锁控制器，
不重复在途命令。先确认 NPU 原生完成，再停止观察，最后读回冻结记录。计时对齐保留 Host
命令起止区间，报告接口字节与真实 DDR 字节的区别，不从静默周期推断内部计算状态。

精确任务修改选择公开 `tasks2Codes` 之前的进程内窗口，原函数及 DLL 文件保持不变；
空变换整图逐字节复现基线。公开任务流含进程相关地址，不用于跨进程持久化恢复。
先单独验证 #3405 全部 KLM 地址整体后移 8KiB：815 个参数对象中仅指令变化，三组完整输出
逐位通过。它是跨层预取的前置候选，必须与实际提前加载及性能收益分开报告。

观察 BOOT 封装复用既有原厂 FMQL 分区契约。完整路由的 setup／hold、内部时钟覆盖、
原功能连接、双向邮箱端点及实际资源先通过检查；AI 最小周期和 GT 例外只接受原对象与原值。
封装后非 PL 字节和填充必须与当前合格 BOOT 完全相同，PL 换序载荷必须匹配本次适配位流。
检查器与拒绝路径测试通过不代表本次硬件已经闭合，部署仍消费本次原生实现报告。

临时 BOOT 维护只调用既有 FAT 审计及原子替换函数。共享锁内同时核验当前 boot_id、设备所有者、
上一批原生关闭／零在途分配和 PID 创建身份；无设备 fd 不能单独放行。安装、回退及正常重启
各自预留有限次数，失败不补用，读回备份作为唯一回退来源。维护程序不初始化 SDK。

观察器的写掩码 popcount 与累计进位链在完整布线后成为临界路径。选择对所有观测事件、
地址和 STOP 统一增加采样级，保留原始采样 tick；不只延迟写字节数而破坏时间箱内的对应关系。
最终事件进入累加器后才发布结束，保持原窗口与计数语义。失败路由 DCP 仅可用作下一轮增量
布局种子；其物理位置可复用，时序与部署资格必须重新检查，不增加例外。

跨层预取采用“前层提前广播＋后层小写入建立完成依赖”。直接删掉四个初始加载会触发原生
`KLM has no last inst`，因此保留每广播 32 字节、合计 128 字节的逻辑读取，写入后层数学任务
不读取的 KLM `[0,32)` 暂存区。72KiB 首块权重在前层任务 512 前装入 `[8KiB,26KiB)`，
前层原访问仍在低 8KiB；后层其余 KLM 访问统一上移，最大 62KiB。没有跳过原生依赖生成。

新增共享权重引用会移动前层输出槽位，必须一起重映射其 200 个 ETM 输出 Tile；全部参数引用
分别绑定同一份原始权重字节。仅两层指令参数变化。维护工具逐字节复现已通过三输入完整回归的
候选，全部 KLM 访问、算子边界及共享存储检查通过。暂存写入只负责依赖，实际重叠和性能以板测为准。

实际接口记录与层进度采用区间对齐，不强行形成单一精确层边界。只以完整内部箱计算事件下界，
以可能相交箱计算上界；跨层箱不按时间比例分摊。预取收益同时检查前层、后层和两层合计，
完整调用另用没有打开探针的帧比较，防止把开销转移误记为端到端加速。

运行是否成功与硬件是否安全关闭分别记录。临时维护允许原生失败但已独立保存 failed-closed、
真实退出码和零分配证明的批次进入原 BOOT 回退；仍须确认进程结束及独占。没有原生关闭证明
的失败保持封锁，不因进程退出而放行，也不重用失败批次的 SDK 预算。

FMQL 封装保留原位流文件名，使镜像头的非 PL 元数据也逐字节一致；只将新适配 BIT 复制到
相同名称后交给原厂工具，不编辑生成的 BOOT。原生封装成功与分区审查成功分别保留，不能以
文件名差异无害为由放宽非 PL 区域检查。

三组实板完整输出一致，跨层预取只观察到微小的两层合计改善，完整调用没有可确认收益。
保留预取候选及工具作为实验，不切换默认性能路径。接口箱宽大于该局部收益，不能用粗分箱
证明重叠的具体时间；直接 MPE 停顿及实际 DDR 事务仍未知。数值、波动及时间线统一维护于访存诊断页。

下一轮先讨论中间激活的条带交接及剩余布局／类型转换，要求同时保留输入复用和量化步骤。
本批已恢复原 BOOT、核验无所有者并结束全部负载；新的方案尚未启动实现。
