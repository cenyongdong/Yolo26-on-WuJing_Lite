# ADR_53：1×1 卷积小空间分块与等价 Matmul 对照

## 性能变化

640×640 FP16。三处慢 1×1 卷积在同一 ELF 下比较，区域时间包含各自的转置、Copy 或独立 SiLU。

| 方案 | 三个区域合计 | 提交＋原生等待均值 | 完整文件调用均值 | 相对原图完整调用 |
|---|---:|---:|---:|---:|
| 原始卷积 | 53.022 ms | 195.832 ms | 222.683 ms | 基线 |
| 20×20 分块 | 26.856 ms | 168.881 ms | 196.086 ms | **节省 26.597 ms** |
| 统一 Matmul | 58.672 ms | 200.660 ms | 227.192 ms | 慢 4.509 ms |

采用 20×20 布局继续研究。Matmul 的测得变化适用于这一组三层及其编译后布局。[三方案板测](../FPGA/yolo26_lite/evidence/pointwise-board-r1.json)

日期：2026-11-14。状态：首轮三图离线及有限板测完成；继续优先小空间分块与转换削减。

## 依据与决定

[原生诊断](../FPGA/yolo26_lite/NPU-DIAGNOSTICS.md) 中 1×1 卷积占主要层时间，
慢层最终指令的输入读取计划存在重复。保持输入 640×640、one-to-one、FP16 参数和激活语义，
在隔离适配图上先改最慢一层，再依据完整数值与收益扩展；原图及已通过的复制削减图保持。

1. 小空间方案把独立像素序列分组为内部 batch，目标先取 20×20。
   NCHWc16 在变换前后各有一次通道块／像素组转置；只对 stride=1、无 padding 的普通 1×1 使用。
   内部 batch 不是新图像，也不改变外部 batch=1。参数字节保持，由原厂 generate 重新规划和编码。
2. 再比较等价 Matmul：将空间像素展平、保留 packed 通道收缩及 bias／SiLU。
   是否需要真实重排由生成结果确认，不因逻辑 Reshape 就假设零开销。
3. 完整零指令视图检查及至少三种固定输入数值对照先完成；保留完整输出。
   分块可能改变 FP16 累加次序，先报告逐位／误差实值，不能把数学等价当作逐位等价或 mAP 通过。
4. 板测比较同一 ELF、输入、SDK、BOOT 和默认 OCM；每个合格图独立新启动，
   每批 3 次预热、12 次普通调用、3 次原生诊断。记录原层和新增转换的合计，最终以完整提交＋等待及调用墙钟为准。
   图失败不消耗其剩余预算，也不盲目重复。共享锁、原生完成及排空边界保持，不写 BOOT。
5. 指令分析同时纳入卷积与两侧转换的读取／写入请求。为转置的正步长向量扩展地址并集统计，
   独立手算检验空洞和重叠；这些仍是静态请求，不是 DDR 事务或等待周期测量。

## 验证与当前状态

正步长 ETM 分析四项、映射六项和区域边界三项独立测试通过。三层 20×20 与等价 Matmul
均已通过完整视图检查，以及三种输入相对原 FP16 和 FP32 ONNX 的既有检测 fixture 门槛。
两图原始张量与原 FP16 均非逐位一致，mAP 未验收；完整原值与误差见
[离线证据](../FPGA/yolo26_lite/evidence/pointwise-offline-r1.json)。板端性能独立验收。

有限板测入口已固定两种候选的图／RAW 身份，拒绝跨模型互换、实时采集、UInt8 输入及其它 OCM 策略。
9 项包契约测试、ARM64 编译链接及 11 项 CPU 测试通过；源文件与构建清单一致。
三批使用同一 ELF `6989474809ddc8594ce5f3e73cd2105f66267b86013e6d7e1926f8f7b78c0760`。
构建本身未启动 SDK，设备所有者为空且已释放锁；构建原值在 `.local/yolo26-tile-build-r2/returned`。

三层扩展曾触发下游 Concat 的视图归并缺口；加入显式输出 Copy 后通过，成本纳入区域总和。
Matmul 初版仅删除 packed 权重的 H/W 维度，数值失败，未上板；修正为在 NHWC/HWIO 逻辑量化图上
改写，再由原厂 adapt 生成 IOo16i16 的参数布局。后者改变存储排列，保持权重的实际数学含义。
这些失败不覆盖原值，当前问题见 [D57](../DIFFICULTIES.md#新增开发问题)。

三批 54 次板测通过并安全关闭。20×20 方案提交＋等待减少 13.76%，包含转换的目标区域合计约减半；
统一 Matmul 则变慢。完整文件调用与分层明细只维护在
[NPU 诊断](../FPGA/yolo26_lite/NPU-DIAGNOSTICS.md)。
分块核心变快后，转置／Copy 成为区域主要成本；后续先传播兼容布局、分析目标区直接写入及剩余慢层，
保留完整视图约束。Matmul 逐形状选择，不一律替换；本轮未切换默认图，未验收 mAP 或持续 30FPS。
当前两个候选均相对原始图开发，不能直接叠加此前复制削减的收益。

标明 1×1 所在组件、原层编号和实测时间，不按相似形状猜测位置。
