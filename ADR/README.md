# YOLO26l 开发决策与性能变化

提交＋原生等待是板端 SDK 调用区间。完整文件调用还包含输入准备、输出读回和 PS 后处理。视频 FPS 来自真实新帧计数。表中标注了跨阶段累计、同批对照和仿真结果，每篇决策附对应原始证据。

| 决策 | 主题 | 关键性能变化 |
|---|---|---|
| [ADR_50](ADR_50.md#性能变化) | 有界缓存与最新窗口 | 独立收益待对照。现有整机采集到显示采用 P95 124.016 ms |
| [ADR_51](ADR_51.md#性能变化) | OCM 放置和逐层计时 | 默认提交＋等待 195.220 ms，三种显式请求均较慢 |
| [ADR_52](ADR_52.md#性能变化) | Split/Concat 复制消除 | 完整调用 222.518 → 220.062 ms，节省 2.456 ms |
| [ADR_53](ADR_53.md#性能变化) | 三层 1×1 的分块与 Matmul | 20×20 完整调用省 26.597 ms，统一 Matmul 慢 4.509 ms |
| [ADR_54](ADR_54.md#性能变化) | FP16 十二层布局、生产者共享输出 | 首轮至十二层提交＋等待累计省 73.953 ms。同批完整调用省约 47.33 ms，后续共享输出再省 9.927 ms |
| [ADR_55](ADR_55.md#性能变化) | 跨分支二维分块传播 | 两个候选完整调用分别慢 1.564、1.423 ms |
| [ADR_56](ADR_56.md#性能变化) | INT8 混合精度与读回 | 混合精度完整调用省 39.0522 ms，同图读回改造另一次对照省 9.5587 ms |
| [ADR_57](ADR_57.md#性能变化) | 真实访存观测与权重预取 | 预取局部省 0.006315 ms，完整调用慢 0.003304 ms |
| [ADR_58](ADR_58.md#性能变化) | USB 摄像头采集 | 直接 V4L2 和项目采集均为 8.25 FPS |
| [ADR_59](ADR_59.md#性能变化) | 静态 512×384 与文件回放 | 跨阶段完整调用 82.5106 → 36.079 ms。最终 600 秒回放 30.820 FPS，逐秒均达 30 |
| [ADR_60](ADR_60.md#性能变化) | 自研 DMA、PL 和 720p60 实时闭环 | 寄存化后首帧仿真增加 1.008 ms，最终时序通过。旧相机复测有效推理 8.777 FPS |
