# ADR_52：YOLO26l 局部复制消除与 1×1 卷积映射实验

## 性能变化

640×640 FP16，同一 ELF 对比原图与保留必要 Slice 的复制削减修正版。

| 指标 | 原图 → 修正版 | 节省 |
|---|---:|---:|
| 完整文件调用均值 | 222.518 → 220.062 ms | **2.456 ms** |
| 提交＋原生等待均值 | 195.687 → 193.486 ms | 2.201 ms |
| Copy＋Slice 层时间 | 4.499 → 2.266 ms | 2.233 ms |

修正版的完整板端输出逐位一致。首版复制消除的数值失败单独保留，性能结论来自修正版。[同程序对照](../FPGA/yolo26_lite/evidence/copy-slice-board-r3.json)

日期：2026-11-14。状态：采用隔离候选方式；保留必要 Slice 的修正版完成有限板测。

## 依据

[ADR_51](ADR_51.md) 的板测确认主要层时间在 1×1 卷积，切换三种 OCM 策略未改善性能。
Copy 与 Transpose 的直接成本较小，但存储布局可能影响后续卷积复用，不能只据节点自身耗时排除。
原始量化参数、one-to-one 分支及无 NMS 语义继续保留。

## 决定

1. 在独立目录改写适配图的局部数据依赖，再由原厂 generate 重新规划存储并编码指令。
   不直接修补生成 RAW 的地址，不更改默认部署模型，不全局关闭 CopyFtmpPass。
2. 首个候选只处理整个 Split 按原顺序形成 Concat 连续前缀的两个 Copy。
   复制输出只能被该 Concat 消费；dtype、量化、packed 布局及顺序须相同。
3. 重新生成后检查全部零指令视图，包括 Concat 后缀，证明同 chunk、连续偏移与完整尺寸；
   上游输出与 Concat 前缀同地址，前缀没有其它指令写入者。初版只检查前缀的缺口见下方失败记录。
   静态证明通过后，对三组固定输入作 Host 后端生成图模拟，保留完整原值并与同身份基线比较。
   编译成功或节点减少均不单独构成数值／性能通过。
4. 首组通过后才扩展其它已识别候选；部分 Split、非连续轴和其它存储冲突单独处理。
   板测仍使用单次启动、继承锁、已证明完成后释放的原路径，候选身份须显式限定。
5. 1×1 卷积分别研究 K/C 时间循环、片上输入／权重／部分和复用，以及等价 Matmul 映射。
   日志循环不是 DDR 事务。固定输入模拟不能证明 mAP；数学等价不保证 FP16 累加顺序逐位相同。
   先获取可验证的生成指令与输出，再评估需要增加的重排／激活成本。

## 验证与限制

首个扩展候选实板数值失败，入口已隔离；原图 18 次通过，候选只执行两次即停止，均安全关闭。
已定位到生成零指令 Concat 的后缀 chunk 不连续，原前缀检查范围不足。新增完整视图检查；
父张量前缀折叠的后续图同样被离线拒绝，未上板。后续改写必须先通过所有零指令视图的完整关系检查，
Host 模拟通过不得代替实际物理别名验证。保留原生失败码及之前离线验收的有限范围。

保守后续路径保留真正被计算分支使用的一次显式 Slice，并删除未使用的直通 Split 输出；
Concat 以完整父张量作为前缀。它减少两次原 Copy 为一次分支 Slice，避免嵌套归并冲突。
八组修正版已通过三组完整模拟逐位比较、69 组生成与实际放置的视图检查及 18 次 NPU 推理。
仅其新哈希进入有限文件入口，旧失败哈希明确拒绝，默认部署图仍保留原图。
沿用已验证的同一 ELF、默认 OCM，最后三次采样，对照已有同 ELF 原图批次；
提交＋等待减少约 2.201ms（1.125%），完整输出逐位一致，安全关闭。
不再次运行失败图或复活旧剩余预算；完整计时及实际次数在唯一结果页维护。

同身份基线追加最终指令日志，已确认慢 1×1 输入请求的重复区域，优先输入跨 K 复用；
不将该静态统计回写为实测 DDR 字节或确定的停顿占比。

状态与实测结果维护在 [NPU-DIAGNOSTICS](../FPGA/yolo26_lite/NPU-DIAGNOSTICS.md)，
失败边界记入 [D56](../DIFFICULTIES.md#新增开发问题)。原始图与失败产物均不覆盖。
没有 DDR 停顿或真实流量证据时，不把低有效吞吐直接归因为带宽饱和。
